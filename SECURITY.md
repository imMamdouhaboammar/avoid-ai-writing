# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 3.29.x  | :white_check_mark: |
| < 3.29  | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in Avoid AI Writing or any of its sub-agent skills, please do NOT open a public GitHub issue.

Instead, please report security vulnerabilities directly to:
- **Author**: Mamdouh Aboammar
- **GitHub**: [@imMamdouhaboammar](https://github.com/imMamdouhaboammar)
- **Security Advisory**: Submit a private report via [GitHub Security Advisory](https://github.com/imMamdouhaboammar/avoid-ai-writing/security/advisories/new)

Please include:
1. Description of the issue and potential impact
2. Steps to reproduce or proof-of-concept
3. Affected components (e.g., CLI, detector regex, or specific agent skill)

We take security seriously and will acknowledge your report promptly.
